# 1. Vue d’ensemble de reality.eth

reality.eth est un oracle optimiste fondé sur des questions, des réponses et des bonds contestables. Le dépôt regroupe contrats, bibliothèque de templates, interface et indexeurs.

Une question devient une assertion économique : un répondant propose une valeur, d’autres peuvent la contester et le résultat final dépend du mécanisme d’arbitrage configuré.

Le parcours suit les contrats, le format des questions, le délai de contestation et les outils qui rendent l’état lisible par une DApp.

Cette documentation décrit le code source et ses limites, sans exécuter de build ou de déploiement.
